### PYTHON CAPSTONE PROJECT
Descriptions

Explore Book Bot, a capstone project that explores the use of automated programs to improve and modernize library management.

Our project demonstrates how automation can help streamline library processes, improve accessibility, and create a more efficient way of managing books and library-related tasks.

This project was developed as part of our undergraduate capstone in Statistics and showcases the application of programming and analytical concepts to a real-world library management problem.
